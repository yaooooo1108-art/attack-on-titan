網頁設計作業心得
本次作業以《進擊的巨人》為主題，製作了一個包含七個分頁的主題網站，分別為作品介紹、周邊展示、軍團報名、人物介紹、捐款網站、OP／ED 歌曲介紹、推薦網站及設計理念。首頁主要介紹作品的故事大綱與受歡迎的原因，並透過導覽按鈕連結至其他頁面，讓使用者能依照興趣瀏覽不同內容。
在網頁設計方面，我運用 HTML 建立網頁架構，並搭配 CSS 調整背景色彩、字體、圖片大小、間距與版面配置。首頁使用 Flexbox 排列導覽按鈕，並加入滑鼠懸停時的變色與移動效果；人物介紹頁利用表格整理角色資料，周邊展示頁則呈現個人收藏與購買地點。此外，我也使用 Bootstrap 製作軍團介紹的分頁切換、手風琴式招募文案，以及軍團報名表單與捐款表單，讓網站具有更多互動性。
製作過程中，我遇到的挑戰主要是不同頁面的版面配置與樣式調整，例如如何讓圖片和文字呈現得更整齊、如何設計滑鼠懸停效果，以及如何讓各個頁面的配色符合《進擊的巨人》的主題。透過反覆修改 CSS 與嘗試不同的排版方式，我逐漸熟悉網頁樣式的設定，也學會運用 Bootstrap 簡化部分介面設計，提升製作效率。
透過這次作業，我更加熟悉 HTML、CSS 與 Bootstrap 的應用，也學習到如何將不同功能整合成一個完整的多頁式網站。從作品介紹到周邊展示、軍團招募及歌曲推薦，每個頁面都有不同的設計目的，讓我更了解網站規劃需要考量內容安排、視覺風格與使用者操作體驗。這次經驗不僅提升了我的網頁設計能力，也培養了我解決問題與調整細節的能力，讓我對未來製作更完整的網站有更多想法。
